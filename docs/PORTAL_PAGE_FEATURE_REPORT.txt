InfraGate Portal Page and Feature Report
Generated: 2026-03-22

Current product (October 2026)
- One portal: devops-frontend. frontend/ and admin-frontend/ are not in this repo.
- Step-by-step behavior for on-call, IAM, changes, incidents, problems, maintenance, and webhooks is docs/FLOWS.md.
- The inventory below is the March 2026 three-portal snapshot. Do not treat its routes as the current map.

Scope
- This report covers all page files found under:
  - frontend/pages
  - admin-frontend/pages
  - devops-frontend/pages
- It is intended as a route-by-route feature inventory for product review, release review, and onboarding.

Legend
- Shell: application bootstrap or document wrapper
- Entry/Auth: login, redirect, password reset, verification, auth-routing pages
- Navigation: page is part of a normal portal workflow and is intended for users to visit directly
- Detail/Action: a feature page focused on a specific record or operation
- Redirect/Internal: route exists but immediately redirects or acts as an internal runtime endpoint

4. CROSS-PORTAL NOTES
======================================================================

Notifications
- The three portals now rely primarily on topbar/drawer notifications.
- The standalone /notifications routes remain for compatibility but redirect:
  - user portal -> /history
  - admin portal -> /requests
  - DevOps portal -> /tickets

Incident numbering
- Incident workflows expose ServiceNow-style numbering with INC-prefixed identifiers.
- This is visible in:
  - DevOps portal incident pages
  - user portal incident views
  - ops command center and incident workspace views

Operational feature concentration
- The DevOps portal contains most of the advanced operational features:
  - gates
  - promotions
  - K8s health
  - drift
  - rollback
  - risk
  - command center
  - notification analytics

Administrative feature concentration
- The admin portal contains most of the governance and lifecycle administration pages:
  - users
  - teams
  - access review
  - project governance
  - requests and approvals

User feature concentration
- The user portal focuses on request creation and request follow-up:
  - self-service requests
  - templates
  - project/team visibility
  - history
  - assigned incidents
