# Code of Conduct

## Our Commitment

We want InfraGate to be a respectful, practical, and welcoming project for everyone who uses or contributes to it.

That means we aim to make participation safe for people of all backgrounds, experience levels, identities, and communication styles.

## Expected Behavior

Examples of positive behavior include:

- being respectful and constructive
- assuming good intent while still giving honest technical feedback
- helping others learn and contribute
- keeping discussions focused on the work and the user impact
- accepting feedback gracefully

## Unacceptable Behavior

Examples of unacceptable behavior include:

- harassment, intimidation, or discrimination
- personal attacks, insults, or dismissive behavior
- publishing private information without permission
- deliberately hostile or exclusionary conduct
- repeated bad-faith arguing that blocks collaboration

## Scope

This code of conduct applies in:

- GitHub issues
- pull requests
- code review comments
- discussions related to the project

## Enforcement

Project maintainers are responsible for clarifying and enforcing this code of conduct.

They may remove, edit, or reject comments, issues, commits, code, or other contributions that violate these standards.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the maintainers.

For security-sensitive concerns, follow [SECURITY.md](./SECURITY.md) instead of reporting publicly.

## Project Standard

This document is intentionally short and practical. The goal is simple: keep InfraGate collaborative, useful, and safe for contributors and users.
